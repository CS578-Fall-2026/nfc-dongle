# NFC dongle

CircuitPython on a Raspberry Pi Pico 2 W. On power-up it types one fixed string as a US keyboard, then prints each NFC tag ID on the USB serial console.

## Parts

- Raspberry Pi Pico 2 W
- PN532 module
- Four jumper wires
- USB cable from the Pico to a computer

## Wiring

| Pico label | Pico pin number | PN532 pin |
| --- | --- | --- |
| 3V3(OUT) | 36 | VCC |
| GND | 38 | GND |
| GP4 | 6 | SDA |
| GP5 | 7 | SCL |

The labels are printed on the underside of the Pico. Hold the Pico with the USB connector at the top and the chip side up. The left column counts 1 to 20 from top to bottom, so GP4 and GP5 are pins 6 and 7. The right column counts 21 to 40 from bottom to top, so 3V3(OUT) is pin 36 and GND is pin 38.

Set the mode switches on the PN532 module for I2C. On most modules that means switch 1 ON and switch 2 OFF. If the board prints the settings, follow what it says for I2C.

## Installing CircuitPython

1. Download the CircuitPython `.uf2` for the Pico 2 W from https://circuitpython.org/board/raspberry_pi_pico2_w/.
2. Hold BOOTSEL and plug the Pico in. A drive named RP2350 appears.
3. Copy the `.uf2` onto that drive. The drive comes back as CIRCUITPY.

## Copying the program

Copy `code.py` onto CIRCUITPY, and copy the `lib` folder in next to it. `lib` contains the Adafruit HID, PN532, and BusDevice libraries this program imports. These source files were copied from the Adafruit CircuitPython Library Bundle dated 2026-10-23; they are not generated by CircuitPython.

The string it types is `TYPE_THIS` at the top of `code.py`.

## Running

Each time the Pico gets power it types `TYPE_THIS` into whatever window is focused, about a second after USB connects. Click a text field before plugging it in if you want the string to land there. The computer is assumed to be using a US keyboard layout.

Tag IDs are printed on the serial console, not typed. In Thonny, pick the CircuitPython interpreter and watch the Shell. A tag on the reader prints a line like:

```
NFC 04:A1:B2:C3
```

The same tag held in place prints once. Take it away and put it back to read it again.
